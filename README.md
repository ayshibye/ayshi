# Ayshi — Personal Portfolio

A responsive portfolio for Noorea Taj Ayshi, a 4th-semester CSE student exploring software development, game development, programming, and creative technology.

## Files
- `index.html` — page structure
- `style.css` — visual design and responsive layout
- `script.js` — rendering and navigation behavior
- `content.js` — editable portfolio content
- `images/profile.jpg` — profile photo
- `images/paintings/` — artwork gallery

## Run
Open `index.html` in a browser, or deploy the folder with GitHub Pages.

## Customize
Edit `content.js` to add projects, skills, education, or artwork.
